# RAA Sidebar Downloader (strict)

Flux imposé :
1. ouvrir la page racine RAA
2. lister les années
3. choisir une seule année
4. lister les mois de cette année
5. choisir les mois
6. charger les PDF
7. télécharger

Cette version refuse les liens hors de la branche `/Publications/Recueil-des-actes-administratifs`.
